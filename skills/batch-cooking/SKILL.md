# Batch Cooking

When asked to do batch cooking, make sure you know:
- How many servings per unit.
- How many units.
- Where the groceries will be bought. Use this to look up which ingredients are available, and in which sizes.
- What macros to aim for per serving.

The food will be frozen. Optimize the recipe for that: choose dishes and ingredients that freeze and reheat well.

When designing recipes, make sure to:
- Use only whole units of ingredients. If the grocer sells tomatoes in 400 g cans, use 400 g or a multiple of that, so the user doesn't end up with half a can of tomatoes left over.
- Optimize for as few measurements as possible for the cook.
- Use the [recipe-toolchart](../recipe-toolchart/SKILL.md) skill to produce the recipe for the cook.
